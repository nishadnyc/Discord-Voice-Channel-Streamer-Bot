Secure admin panel

Discord OAuth login. Join or leave channels remotely and manage per-server permissions.

🤖 Slash Commands

/join Joins your voice channel and outputs a web stream link.
/leave Disconnects the bot from the current channel.
/tts <message> Sends a Text-to-Speech message to the active voice channel.
/help Displays the command menu and usage instructions.
